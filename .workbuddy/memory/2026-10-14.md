## tree-sitter-vx：VX 语言的 Tree-Sitter 语法

新建 `tree-sitter-vx/`（vx-toolkit 根目录下），独立可发布的 Tree-Sitter 语法包：

- `grammar.js`：完整语法定义。依据 src/compiler/parser.cpp（C++ 参考）+ compiler/parser.vx（自举）制定。
- `src/scanner.c`：外部扫描器，产出 `_newline/_indent/_dedent`（仿 tree-sitter-python 方案：空白含换行作为 extras；外部 token 零宽；括号内语法不接受外部 token → 续行自然处理；tab=4 列；空行/整行注释不参与缩进比较；支持连续 dedent）。
- `queries/highlights.scm`：语法高亮查询；`test/corpus/vx.txt`：18 组语料测试全通过。
- tree-sitter.json（scope: source.vx, file-types: vx）、README.md、LICENSE(MIT)、.gitignore。

### 语法要点（与参考实现的对应）
- 缩进块 + `:` 块头（func/if/elif/else/while/for/class/struct/enum）；同行块用 `;` 分隔。
- 软关键字 loop/match/enum/union/macro/move 表达式位置回退为标识符；`new` 可作方法/成员名（_name 规则）。
- 单 token 规则（如 break_statement: 'break'）会吞掉匿名 token → 高亮查询需引用命名节点而非 "break"。
- 二义消解：new_expression 用 prec.right（args 并入）；qualified_type/generic_type 用 prec(1)（`new Foo.bar` 的 '.' 并入类型、`new Vec<int>` 的 '<' 并入泛型而非比较）；return_statement 用 prec.right（macro 花括号体内 `return (expr)`）。
- 真实 std 源码驱动的扩展：hex 整数(0x..)、enum 声明（成员 `Name = 值`）、类常量成员、`macro name(params){...}` 花括号块（宏体内 if/while/for 花括号版）、new 支持泛型/点分类型、点分类型 vec.Vec、带类型标注赋值 `i: int = 0`（annotated_assignment）。
