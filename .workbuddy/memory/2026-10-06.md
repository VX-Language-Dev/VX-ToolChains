## 本次完成的修复

### P0-3 后端 translator（前次已完成，本次确认）
- 修复 `go/internal/translator/platform.go` 中错误的 LLVM intrinsic 声明：
  `declare i8* @llvm.memset.p0i8.i64(...)` 返回类型错（应为 void），导致 ARM64/macOS 上 llc 报
  "intrinsic return type expected void, but got ptr"，原生可执行文件无法生成。改为正确的 void 签名。
- `go test ./internal/translator/` 全绿，ARM64/macOS 原生代码生成打通。

### P0-1 lexer CJK / 列号

- 列号改为按 rune 计（原来按字节，CJK 每字符占 3 列）。
- 新增 `TestUnicodeIdentifiers` 回归测试。

### P0-2 语义检查
- `go/internal/semantic/semantic.go` 新增重复声明检查（`DeclareSymChecked`，同作用域冲突报错，允许内层 shadowing）。
- 为 if/while/for/loop/match 各分支/循环体建立独立作用域（`checkBody` 辅助）。
- 补齐函数调用参数数量+类型检查（`inferCallExpr`）。
- 实现 return 类型检查（`checkReturn` 接入 `curFunc`）。
- 新增 TestDuplicateDeclaration / TestShadowingAllowed / TestCallArity* / TestReturn* 等测试。

### P0-7 诊断位置丢失
- `go/cmd/vxc/main.go`：语义/所有权错误原只打印 `err.Msg`（丢失 Pos）。改为调用
  `out.PrintErrorLocation(err.Msg, sourceFile, line, col)`，CLI 现在输出 `  --> file:line:col`。

### P1-8 CLI -o 参数顺序
- Go `flag` 在首个非 flag 参数后停止解析，导致 `vxc source.vx -o out.vxobj` 的 `-o` 被忽略。
- 新增 `reorderArgs()`，在 flag.Parse 前把 flag（含值）重排到位置参数（源文件）之前。两种写法均可用。

### P1-5 所有权单测（报告点名 ownership 无 *_test.go）
- 新建 `go/internal/ownership/ownership_test.go`：TestUseAfterMove / TestParameterReassignment /
  TestMutableAssignmentAllowed / TestBorrowConflict / TestValidProgramNoErrors。
- 关键发现：VX 中 `var` 实为可变（parser 把 VarT 当 mutable，std/error.vx 也重赋值 var 变量），
  **不可变检查只对参数生效**（报告亦言"参数一律不可变"）。测试据此采用参数场景，避免误改 `var` 语义破坏 std。

### Parser class 后函数丢失（报告"struct/class 方法未解析/内容被丢弃"相关）
- `go/internal/parser/parser.go`：class 内含方法时缩进多一层，`parseStructFields` 会把 class 自身的
  闭合 DEDENT 泄漏到顶层循环，导致 class 之后的顶层函数全部丢失（`prog len=1` 仅 ClassDecl）。
- 新增 `skipIndentedBlock()`：遇到方法等复合语句按缩进深度整体跳过，且**保留外层闭合 DEDENT** 给调用方。
- 新增 `TestClassThenFunction` 回归测试。端到端 `vxc` 编译 class+func 程序验证通过。

## P1-5 余下：class/struct 方法体完整解析（新增，全部测试通过）

本次补齐了 class/struct 方法体从 parser → semantic → typeirgen → ownership 的完整管道：

- **parser**：`parseStructFields` 接受 `receiverType` 参数；对 `Func`/`Extern` 调用对应的复合语句解析器并收集到 `Methods`；同时自动注入 `self` 作为第一参数（类型为 struct/class 名称）。
- **semantic**：`collectDecls` 对 StructDecl/ClassDecl 的方法做 mangled name 注册（`TypeName.methodName`）到 `st.Functions`；新增 `checkFuncDecl`/`checkMethodBody`；`checkFuncBody` 遍历 `d.Methods` 调用 `checkMethodBody`，支持 return 类型检查、参数检查等。
- **typeirgen**：`GenerateIR` 对 StructDecl/ClassDecl 的 `Methods` 循环编译为 `FunctionIR`，mangled name 且带独立 `funcID`；`funcReturns` 同步更新。
- **ownership**：`CheckExpr` 对 `*ast.StructDecl`/`*ast.ClassDecl` 递归 `c.CheckExpr(m, 0, 0)` 检查方法体。
- **新增测试**：parser（struct methods）、semantic（方法注册 + return type mismatch）、ownership（class method ownership）、typeirgen（methods 出现在 TypeIR 中）。
- **端到端验证**：`vxc` 编译含 class method 的程序输出 vxobj；`dump_typeir` 显示 `Counter.new`/`Counter.inc`/`main` 三个函数。
